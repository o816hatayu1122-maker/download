Make clip videos from: $ARGUMENTS

Use the `video-clip` skill and follow it start to finish. In particular:

1. **Interview the user before cutting anything.** Ask about the clip style
   (hook-first / digest / plain), the target platform and length, the aspect
   ratio, and captions. Do not assume defaults and start cutting — the answers
   change what you produce, and re-cutting wastes a download and a re-encode.
2. **Find the moments before choosing timestamps.** Check chapters, then build
   a transcript. Never guess ranges.
3. **Propose the ranges with a one-line reason each and get confirmation**
   before spending time on the cut.

If no video was given above, ask for one as part of the interview.
